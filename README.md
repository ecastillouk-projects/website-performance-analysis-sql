# website-performance-analysis-sql

**Project Overview**
This project analyses website performance and customer journey behaviour for an e-commerce retailer using SQL.

The analysis focuses on:
-  Traffic source performance
-  Conversion analysis
-  Website funnel behaviour
-  Device performance
-  Customer journey optimisation

**Business Objective**
The objective of this analysis is to identify opportunities to improve website conversion performance and understand how customers interact with the website journey from session to purchase.

**Tools Used**
PostgreSQL 
GitHub

**SQL Techniques Used**
-  JOINs
-  CTEs
-  Window Functions
-  CASE WHEN
-  Aggregations
-  Funnel Analysis
